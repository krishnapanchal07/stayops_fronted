# StayOps

StayOps is a role-based PG / Hostel management platform.

Phase 1 currently includes the design system, layouts, mock authentication, RBAC, and protected routing.

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
npm run format
```

The app starts at `http://localhost:5173`.

## Demo credentials

Developer-only mock accounts are documented in [`src/mock/AUTH.md`](src/mock/AUTH.md).

Do not show these passwords in the product UI.
